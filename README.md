# 🌱 Geeden – Plant Sale Website

Geeden is a simple and responsive **plant-selling website** created using HTML and CSS. The website provides a clean and attractive interface for browsing and exploring different plants.

## 🌿 Features

* 🏠 Home page
* 🌱 Plant products section
* 🛍️ Plant sale/product display
* 📱 Responsive design
* 📞 Contact section
* 🎨 Clean and simple user interface
* 🖼️ Plant images and icons

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive design
* **SVG / Icons** – Website icons and visual elements

## 📂 Project Structure

```text
Geeden/
│
├── index.html
├── style.css
├── images/
│   ├── plant images
│   └── icons
│
└── README.md
```


## 🎯 Project Purpose

The main purpose of this project is to create a simple online plant-selling website and practice **HTML, CSS, responsive design, Flexbox, and basic web development concepts**.
